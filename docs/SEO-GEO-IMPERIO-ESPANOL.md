# SEO, GEO y citabilidad para «Imperio español»

## Objetivo realista

Convertir Imperio E en una fuente accesible, fiable y útil para consultar y citar. No se pueden garantizar citas de una IA ni una posición concreta: los buscadores y asistentes seleccionan sus fuentes mediante sistemas que el editor no controla.

## Qué se ha preparado

- Contenido principal en HTML del servidor, con URL canónica estable.
- Respuesta directa, secciones legibles, cronología, FAQ y fuentes institucionales.
- Datos estructurados coherentes: `Organization` para la marca editorial, `DefinedTerm` para la entidad histórica, `WebPage`, `BreadcrumbList` y `FAQPage`.
- Imágenes con texto alternativo, atribución y licencia visible.
- Enlazado interno hacia análisis propios y sitemap actualizado.
- Exclusión del popup de camiseta para no interrumpir la primera lectura del pilar.
- Prueba automatizada de título, H1, secciones, fuentes, sitemap, schema y ausencia del popup.

## Criterios de citabilidad

1. Formular respuestas concretas al inicio de cada sección.
2. Separar hechos, convenciones cronológicas e interpretación historiográfica.
3. Vincular archivos, instituciones y bibliografía verificables.
4. Identificar la responsabilidad editorial y mantener una política de correcciones.
5. Actualizar el contenido con cambios sustantivos, sin modificar fechas para simular novedad.
6. Publicar investigación original y transcripciones solo cuando tengan procedencia y revisión.

## Search Console y seguimiento manual

Estas acciones requieren acceso del propietario y no se automatizan desde el código:

1. Inspeccionar `https://imperioes.com/imperio-espanol` después de publicar y solicitar indexación si todavía no está rastreada.
2. Confirmar que `https://imperioes.com/sitemap.xml` se procesa sin errores.
3. Revisar cobertura, canonical seleccionada, experiencia móvil y consultas cada 28 días.
4. Comparar impresiones y clics antes y después de la publicación, sin atribuir causalidad a una sola modificación.
5. Registrar las citas encontradas en respuestas de IA con consulta, mercado, fecha, URL citada y captura o enlace verificable.
